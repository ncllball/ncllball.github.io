## Picker rebuilt (2026-11-02, Uniforms Hub r77, not yet published)

The picker on the Uniforms Hub is now generated by `scripts/build-uniform-picker.js` (pure HTML/CSS; the CMS allows no JavaScript). It applies everything in section 1:
- Jerseys 4001 (baseball A–AAA), 4011 (Majors–Seniors), 4404 (softball Majors), 4408 elsewhere. Coaches pick ST350 (Mens) or LST350 (Womens); John 2026-11-03: never "unisex", which matches Protime (ST350.ADULT, LST350.WOMENS). ST550 is gone.
- The hat step only appears for AAA and up. T-Ball–AA get an "included" note instead.
- Players have no hoodie question. An "Included" step lists the hoodie (one size up), socks and belt. Coaches have no socks or belt.
- Intermediate is added as a baseball division (same as Juniors).
- The last screen is "Your registration answers": each registration question with its numbered answer, the item it orders, what's provided, a list of every option, and Back / Start over / **Go to registration**.
- Measurements follow the sheet: chest ranges for jerseys, tees and hoodies. The LST350 is still pit-to-pit (open #3).

Choices made where the sheet was unclear (Chris's QA round should confirm):
- Socks and belt shown for A and up only (sheet row 13). T-Ball/Kindy show none.
- Softball A/AA player hat is described only as "youth adjustable cap" (open #5). Softball AAA+ still pick a Youth/Adult visor (open #7).
- Youth XL stays where the sheet lists it (open #2). Coach shirts offer XS–4XL in every division (the sheet rows do; open #4).
- There are no product photos for 4001, 4011, 4404, LST350 or 8203, so those steps are text-only.
- The registration question numbers (Q13 etc.) aren't shown yet. Add them to the question text in the script once registration is built.

### Registration questions the picker expects (build Sports Connect to match)

In 2026, each program asked one Hat, Shirt/Jersey and Hoodie question of *all registering users* (players and coaches), required for every division, with unnumbered codes (Baseball shirt: YXS…AXXXL; Softball hat mixed visor/PTS30/HC10 sizes). For 2027, each program asks its own questions, with the options numbered exactly as below (the picker shows the same "N: label" text). The source of truth is the data at the top of `scripts/build-uniform-picker.js`.
