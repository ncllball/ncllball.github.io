# Codex brief: verify the NCLL website against the facts

You are checking that ncllball.com's page sources (the `CMS/` folder of this repo) say the same thing as the league's facts. **This is a read-and-report job.**

## Rules

- **Do not edit any file in `CMS/`, `assets/`, `QR/` or `docs/`, and do not commit or push.** The only file you write is the report (below).
- Do not log in anywhere, post anything, or call any Sports Connect or ncllball.com endpoint that changes data. Use only the read-only `ncll-browser` tools for Sports Connect and the CMS, following `AGENTS.md`. Reading public pages on www.ncllball.com is fine.
- Families read this site on phones; a wrong fee, age or date costs real money or a missed deadline. Report anything you aren't sure about rather than guessing.
- The 2027 fees are final (Jason, 2026-11-03; AAA and Majors $290 in both sports). Sponsor prices are on hold for the new sponsorship lead and are off the site; don't report their absence.

## Report

Write **`_drafts/fact-check-report.md`** with:

1. **Summary**: counts of errors / warnings / questions.
2. **Errors** (the page is wrong): one bullet each, `file:line`, what it says, what the facts say, and the fix in one line.
3. **Warnings** (stale, inconsistent or unclear wording).
4. **Questions** (the facts file itself might be wrong or missing something; say what you'd add).
5. **Script results**: paste the script's report, and note any false alarms you found, with why, so the script can be tuned.

Plain, short sentences. No changes to any other file.
