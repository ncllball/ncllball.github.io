# Division deltas — what changes when you clone Majors

Copy `baseball-majors-rules.md` → `<division>.md`, then change **only** the rows below. Everything else
(common D8 rules, operations, batter's box, courtesy runner, CBO, 8-player rule, minimum
play, supervision, etc.) stays identical to Majors on purpose.

D8 publishes an interleague supplement for **AAA and up only**. For **AA / A / Rookie / Tee
Ball** there is no D8 doc — those rows are NCLL's to write, informed by the comparable-
league research (`SOURCES.md`) and what the D8 siblings do.
